# 버블 슈터

퍼즐보블 스타일의 버블슈터 웹 게임입니다. `bubble-shooter/index.html` 파일 하나로 동작합니다.

## ▶ 플레이하기

**https://hailey1220.github.io/Pair-Programming/bubble-shooter/**

## 조작

- 마우스로 조준하고 클릭하면 발사합니다.
- 같은 색 구슬을 3개 이상 이으면 터지고, 천장과 끊긴 구슬은 떨어집니다.
- 8발마다 천장이 한 줄 내려옵니다. 구슬이 아래 경계선을 넘으면 게임오버입니다.
- 판의 구슬을 모두 없애면 클리어입니다.

## 점수

- 터뜨린 구슬: 개당 10점
- 떨어뜨린 구슬: n개일 때 10 × 2ⁿ점
